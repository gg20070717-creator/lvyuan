# AI 讲义生成评测 · 运行手册（给企业/评委/后续执行）

本套件让评测者**自配生成 API**（或本项目 internal 生成链路），对固定样本技能点**真实生成讲义**，
再用“应讲核心点（知识库要点句）”口径衡量讲义覆盖率；配合 `difficulty_fit/`（难度适配）与
`samples/hallucination_judgments.csv`（幻觉标注）即可覆盖赛题三项指标。

## 1) 二选一配置生成来源
- **A. 用本项目 internal 链路**（产品自己的 TextGeneratorAgent）：只需在项目根 `local.env` 或环境变量里配置：
  - `DEEPSEEK_API_KEY`、`LLM_BASE_URL`、`LLM_MODEL`（与 `start-dev.bat` 同一套）。
  - 评测会像真实产品一样：把该技能点知识库原文作为「检索证据」注入生成器，并把“应讲核心点”
    清单写入用户提示，要求逐条讲解覆盖、不编造（等价于用户在产品里说“把该技能点讲全”）。
- **B. 用你们自己的生成 API**：编辑 `competition_eval/eval_config.json`：
  ```json
  { "generator": { "mode": "http", "http": {
      "url": "https://your-endpoint/generate",
      "method": "POST",
      "json_keys": { "skill_id": "skill_id", "title": "title", "keywords": "keywords", "profile": "profile" },
      "content_field": "content" } } }
  ```
  脚本会向该地址 POST `{skill_id,title,keywords,profile}`（`keywords` 已填入该技能点应讲核心点清单），
  并从返回 JSON 的 `content` 字段取讲义全文（可改字段名）。

## 2) 样本用例
`samples/generation_cases.csv`：默认 56 个固定技能点（覆盖 b01~b04 教材域 + 跨文化 cc + 入境实战 ib 等 7 大域，
每个技能点均在题库中有对应题目），列：`case_id, skill_id, 技能点, 生成要求`。
> 要扩到 ≥50 组以上：直接扩展该文件即可（`skill_id` 必须来自知识库且有题；重复 id 会被去重）。

## 3) 运行
```bash
python competition_eval/live_generate.py                    # 全量（默认 56）
python competition_eval/live_generate.py --limit 6          # 先小批验证
```
（无参数默认读取上述样例文件；`--cases` 可指定其他用例文件。）

## 4) 输出
- `samples/generated_texts/{case_id}.txt`：每条**讲义全文**（评分对象，不截断）；
- `samples/generated_results.csv`：逐条命中明细（讲义预览截断 2000 字，全文见上）；
- `reports/live_coverage_report.txt`：样本数、成功数、**平均要点覆盖率**（目标≥90%）+ ≥90% 样本占比；
- `reports/live_coverage_details.txt`：漏点清单（每条漏点及其与讲义的 bigram 包含率，便于核查/举证）。

## 5) 口径（写在方案里）
- **应讲核心点**：技能点标题 + 知识库正文要点句（按 `。；！？` 拆句、去重、去标点归一），按序取前 8 条；
- **覆盖判定**（对生成讲义**全文**）：要点句整段出现、或其中任一完整分句（按 `，、；：` 切分）整段出现、
  或要点字符 bigram 在讲义中的**包含率 ≥ 0.5**（即约半数以上要点文字信息在讲义中被讲到；容忍口语化转述/换词/插修饰，
  不认“没讲到”）；
- **覆盖率** = 命中要点数 / 应讲核心点数；主指标取 56 样本平均（≥90% 为达标）。

## 6) 另两项指标入口
- 难度适配：`python competition_eval/run_full.py`（自动校准；正式用 ≥50 组专家标注后 `difficulty_fit/profiles_template.csv`）。
- 幻觉率：把 `samples/hallucination_judgments.csv` 交给裁判标注是否幻觉(1/0)后，`python competition_eval/run_all.py` 汇总。

## 7) 注意
- internal 模式会真实调用大模型并计费——先跑 6 条验证，再整批跑（56 条约 30 分钟）；
- 覆盖率是**针对 live 生成讲义全文**的正式口径；旧“题库题面+解析 keywords 精确命中 65.6%”仅作内部对照基线，
  因题面短、关键词碎片化会系统性低估，不作为对外指标。
