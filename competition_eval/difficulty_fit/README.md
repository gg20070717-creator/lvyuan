# 题库难度推荐 vs 专家期望 —— 适配准确率评测模板

目的：把赛题“学习者画像-资源难度适配准确率≥85%”测成一个**有意义、可复现、非 100%** 的指标。
原则：不能由系统自证（否则必然 100%）。这里的“答案”是**外部专家/评审**对该画像“该练哪个难度档”的判断。

## 目录
- `profiles_template.csv`：空白模板（专家填“期望星级”列）
- `profiles_sample.csv`：已填样例（用于演示脚本与口径，含边界样本，含少数 ±1 星分歧）
- `difficulty_rules.json`：系统当前“掌握度→推荐星级”规则（写死，供脚本复算“系统推荐”）
- `evaluate.py`：离线评测脚本（无需 LLM/网络）
- 本文件

## 一、怎么填（一次性、离线）
1. 打开 `profiles_template.csv`；
2. 对每一行画像（含掌握度 mastery_0_1），由**不了解我们推荐逻辑的评审/老师**按 rubric 填“期望应练难度档”：
   - ★1 只考记忆/辨认；★2 理解概念；★3 场景应用；★4 多步分析；★5 综合决策+前置知识；
3. 保存（Excel 另存为 CSV，UTF-8）。

> 重点：评审**不要**看 `difficulty_rules.json`，只看画像与 rubric。期望与系统规则不会逐点一致（尤其边界样本），这正是要测的东西。

## 二、怎么跑
```
python evaluate.py profiles_sample.csv        # 用已填样例演示
python evaluate.py profiles_template.csv      # 填完真值后用
```
输出：
- 系统推荐星级 vs 专家期望：一致/不一致清单
- 精确一致率、±1 星一致率、边界样本一致率
- 建议（不一致集中在哪类画像）

## 三、口径与防“100% 作弊”
- 只统计你**事先没有用它调过系统规则**的样本（训练/评测分离），否则会过拟合出虚高的 100%。
- 若做出来≈100%：多半“专家”其实就是系统规则的镜像，需换更细的边界样本或换评审。
- 报告建议同时给出：样本数、不一致的典型例子与原因——这才像真实评测。

## 四、后续扩展（加分项，不在本模板）
- 对 **AI 生成资源**的实际难度：用独立“难度定标裁判 Agent + 本 rubric”当场量当次生成内容，再与画像期望比对（随机性用多次运行取命中率）。本模板只覆盖题库/推荐档位的可复现基线。
