# 组员协作指南

## 加入仓库

仓库地址：<https://github.com/gg20070717-creator/lvyuan>。

管理员在 **Settings → Collaborators → Add people** 输入组员 GitHub 用户名，发送协作邀请。组员接受后即可克隆和推送代码。

## 开始工作

每次在此项目开始工作前，先运行 `git status` 检查本地改动，再执行 `git pull --ff-only` 拉取当前分支最新版本。保留未提交改动，先解决同步分歧或冲突，再开始修改。

先提交或暂存未完成的改动，再同步主分支并创建自己的任务分支：

```powershell
git switch main
git pull --ff-only
git switch -c feature/your-task
```

同一任务持续使用同一个分支。

## 提交进度

```powershell
git status
git add sinanlike/frontend/src
git commit -m "feat: 调整学情卡片布局"
git push -u origin feature/your-task
```

按实际改动选择需要提交的目录。推送后创建 Pull Request，说明改动和验证结果。未完成工作可先创建 Draft Pull Request，方便组员查看进展。

## 合并前

- 前端改动执行 `npm --prefix sinanlike/frontend run build`，核对相关页面。
- 后端改动执行相关单元测试；数据改动核对技能点、题目及来源。
- 确认提交不包含密钥、数据库、缓存、安装包或日志。
- 更新 `docs/进度记录.md`，记录完成事项和下一步。

## 入口

- Pull Requests：<https://github.com/gg20070717-creator/lvyuan/pulls>
- Issues：<https://github.com/gg20070717-creator/lvyuan/issues>
- 邀请组员：<https://github.com/gg20070717-creator/lvyuan/settings/access>

用 Issue 记录任务负责人、验收条件和进度，通过 Pull Request 关联任务。管理员可在 Settings 中修改仓库名称与可见性。
