

## 总知识库结构

顶层：

```json
{
  "schemaVersion": "1.0",
  "root": {},
  "skills": []
}
```

`root` 是一棵树：`master → book → part(篇，可选) → chapter → section → skill`。

通用节点字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | string | 全局唯一节点 ID |
| `type` | string | `master / book / part / chapter / section / skill` |
| `title` | string | 节点名称 |
| `content` | string | 汇总正文（技能点为原始正文） |
| `parentId` | string/null | 父节点 ID |
| `children` | array | 子节点列表（技能点无此字段） |
| `childIds` | array | 子节点 ID 列表（技能点无此字段） |
| `stats` | object | 仅 book 以上节点：`parts/chapters/sections/skills` 计数 |
| `sourceFile` | string | 仅总库中 book 节点：对应单书 JSON 路径 |

技能点额外字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `keywords` | array | 检索关键词 |
| `categories` | array | 分类标签：概念 / 流程 / 历史 / 考点 / 法规 / 实务 |
| `difficulty` | int | 难度 1-5 |
| `status` | string | 学习状态，默认 `locked`，可用于进度点亮 |
| `dependencies` | array | 前置技能点 ID 列表（同节内按顺序串联） |

`skills` 是所有技能点的平铺数组，可直接遍历做检索；通过 `parentId` 可回溯到
对应章、节，或通过 `id` 在 `root` 树中定位完整上下文。

## 题库结构

顶层：

```json
{
  "schemaVersion": "1.0",
  "total": 713,
  "targetSkills": 713,
  "questions": []
}
```

每题字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `题目` | string | 题干 |
| `选项` | array | 4 个选项（A/B/C/D） |
| `章-节-点` | string | 出处定位，格式：`书名 / 章 / 节 / 技能点` |
| `答案` | string | 正确选项字母，如 `A` |
| `解析` | string | 简单解析，不超过 50 字 |
| `难度` | int | 题目难度 1-5（缺失时按映射技能点难度回退，默认 3） |

## 示例

技能点：

```json
{
  "id": "skill_00001",
  "type": "skill",
  "title": "导游服务的产生与发展",
  "content": "……正文……",
  "keywords": ["导游服务", "产生", "发展"],
  "categories": ["概念", "历史"],
  "difficulty": 3,
  "status": "locked",
  "dependencies": [],
  "parentId": "book_001_001_001"
}
```

题目：

```json
{
  "题目": "我国第一个五年计划（“一五”计划）的起止时间是？",
  "选项": ["1950-1955", "1953-1957", "1956-1960", "1958-1962"],
  "章-节-点": "全国导游基础知识 / 第一章 / 第一节 / “一五”计划的顺利实施",
  "答案": "B",
  "解析": "“一五”计划实施时间为1953年至1957年。"
}
```

##、开发提示

- 单书知识库结构与总库一致，只是没有 `master` 层和 `sourceFile`。
- 总库中 ID 带书籍前缀（如 `b01__skill_00001`），保证跨书唯一；单书内无前缀。
- 题目按技能点逐个生成，可通过 `章-节-点` 字段反查知识库，也可按教材/章/节筛选组卷。
