> `knowledge/loader.py`（支持按文件名加载）、`services/skill_tree.py`（新增 inb/cus 分支）。

## 二、数据结构（与既有 713 技能点库同构）

- 顶层 `{ schemaVersion:"1.0", root:{master}, skills:[...] }`
- 树：master → book（领域分组）→ chapter（手册/主题）→ section（可选）→ skill
- 技能点字段与 `data/知识库与题库说明.md` 一致（id/type/title/content/keywords/categories/difficulty/status/dependencies/parentId）
- content 为 80-250 字精炼正文，末尾标注来源手册路径与章节（可追溯回 docs/information 原文）
- 领域库当前无题库 → 学习闭环自动走 **LLM 简答路径**：quiz_user 检测到主题无选择题即返回
  essay_ready 信号 → 管家推荐简答 → EssayQuestionAgent 出题（注入技能点原文）→ 判分 → 掌握度 → 技能树点亮。
  若日后补配 `data/qb_<domain>.json`（结构对齐 master_question_bank.json），插件自动装载选择题，
  且题库条目可带「技能点ID」字段直连技能点（重名标题场景唯一可靠；主库 713 仍按标题匹配）。

## 三、如何加载（三种方式）

```python
# 1) 直接加载数据
from brain_of_cloud.knowledge.loader import KnowledgeBaseLoader
kb = KnowledgeBaseLoader(kb_filename="kb_inbound.json").load()
print(kb.stats)  # books/skills/questions

# 2) 领域插件（与 TourGuidePlugin 同接口：search/list_knowledge_points/questions…）
from brain_of_cloud.plugins.domain_plugin import DomainKnowledgePlugin
plugin = DomainKnowledgePlugin("inbound")

# 3) 注册表（推荐）
from brain_of_cloud.plugins.registry import build_plugin
plugin = build_plugin("inbound")          # 或设环境变量 BOC_DOMAIN=inbound 后 build_plugin()
```

- 可用领域名：`exam`（默认 713 资格证库）/ `guide_practice` / `inbound` / `customizer`
- FastAPI 装配（`api/app.py`）与 Orchestrator 默认插件均走注册表；`BOC_DOMAIN=inbound uvicorn ...` 即以入境游领域库启动整套训练服务
- 技能树：`services/skill_tree.py` BRANCHES 新增 `inb`（入境游接待 10 节点）与 `cus`（旅游定制师 8 节点）两分支（95 节点）；节点关键词对齐领域库技能点，管家点亮与掌握度自动点亮机制不变
- 目录树兼容领域库「book → chapter → skill」无 section 结构：catalog 会把章下直接技能点包成同名节，前端统一按「章→节→技能点」渲染

## 四、学习路径数据使用（已在学习流程接线）

- `domain_learning_paths.json` 按领域给出阶段序列（阶段目标/覆盖 book/建议学时/产出物/过关门槛/语料锚点）
- 已接线：
  - `services/domain_paths.py` —— 按插件 plugin_id 读取领域学习路径（惰性缓存）
  - `GET /knowledge/learning-path` —— 返回当前领域的阶段路径（阶段书单已解析标题），供前端渲染/阶段组卷
  - 计划生成（LearningPlannerAgent + Orchestrator）—— 注入当前知识库结构与推荐学习路径，领域模式下计划按领域教材/阶段编排（不再写死 4 本考试教材）
- 阶段顺序即推荐教学顺序；book id 与各领域 JSON 一一对应，可按书筛选技能点组卷或做阶段测评
